# ecommerce-customer-csat-score-prediction
This project implements an end-to-end Deep Learning Artificial Neural Network (ANN) designed to predict discrete CSAT ratings automatically from interaction telemetry and customer remarks

Local presentation app: run `.\run_demo.ps1`, then open http://127.0.0.1:8501.
See [DEPLOYMENT.md](DEPLOYMENT.md) for the video walkthrough, CSV format, model limits, and tests.
